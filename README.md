## О проекте

«Между Булок» — учебный frontend-проект, в котором разработана концепция сайта небольшого стритфуд-кафе. Это не сайт действующего заведения и не сервис для реального оформления заказов: адрес, меню, цены и интерьер используются как демонстрационные данные.

Задача проекта — показать, как средствами обычных HTML, CSS и JavaScript можно создать выразительный одностраничный сайт с авторской визуальной системой, анимациями и интерактивными сценариями.

## Что реализовано

- **Атмосферная главная:** крупная типографика, фирменная графика и анимация при прокрутке.
- **Интерактивное меню:** категории блюд, карточки позиций и выбор соусов.
- **Демонстрационная корзина:** добавление и удаление позиций, изменение количества и подсчёт суммы.
- **Сценарий оформления:** форма с проверкой полей и выбором времени самовывоза. Отправка никуда не выполняется — финальный экран имитирует завершение сценария.
- **Зона кафе:** интерактивный выбор условного места в зале.
- **Дополнительные детали:** FAQ, нижняя навигация, адаптация под мобильные экраны и анимации интерфейса.

## Технологии

| Технология | Использование |
| --- | --- |
| HTML5 | Семантическая структура и содержимое |
| CSS3 | Стили, адаптивная сетка, анимации и визуальные эффекты |
| Vanilla JavaScript | Меню, корзина, форма и интерактивность |
| Local Storage | Локальное сохранение демонстрационной корзины |
| GitHub Pages | Бесплатная публикация статического сайта |

Проект не требует Node.js, сборщика, фреймворков или установки зависимостей.

## Запуск

### Посмотреть онлайн

Откройте [eugggeneee.github.io/mezhdubulok](https://eugggeneee.github.io/mezhdubulok/).

### Запустить локально

1. Скачайте репозиторий или клонируйте его:
   ```bash
   git clone https://github.com/eugggeneee/mezhdubulok.git
   ```
2. Откройте папку проекта.
3. Запустите `index.html` в современном браузере.

Для локального просмотра сервер разработки не обязателен. Для публикации на GitHub Pages используется корень ветки `main`.

## Публикация на GitHub Pages

1. Откройте **Settings → Pages** в настройках репозитория.
2. В блоке **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/(root)`.
4. Сохраните настройки и дождитесь завершения публикации.

После публикации сайт будет доступен по адресу:

`https://eugggeneee.github.io/mezhdubulok/`

## Важные ограничения

- Проект предназначен для обучения и демонстрации frontend-разработки.
- Корзина хранится только в браузере пользователя.
- Форма не отправляет данные на сервер и не создаёт реальный заказ.
- Онлайн-оплата, авторизация, база данных и административная панель не реализованы.
- Шрифты загружаются из Google Fonts; при отсутствии соединения используются системные резервные шрифты.

## Учебные цели

- Практика семантической HTML-разметки.
- Создание адаптивного интерфейса без CSS-фреймворков.
- Работа с DOM, событиями и состоянием интерфейса.
- Реализация клиентской логики корзины и формы.
- Использование CSS-анимаций и JavaScript для интерактивного повествования.
- Публикация статического проекта через GitHub Pages.
